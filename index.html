Exportación y respaldo

Excel compatible

Genera las hojas Parámetros, Empleados, Planilla y Aguinaldo con las columnas del archivo original. Incluye todos los pagos, sin depender del filtro de quincena.

Respaldo privado

Descargá un respaldo JSON para recuperar tus datos o trasladarlos a otro navegador. El Excel se exporta como reporte editable; para volver a la aplicación, usá el respaldo JSON.

Uso en GitHub Pages

Publicá solamente index.html. No subás el Excel ni los respaldos: contienen información de empleados. La aplicación usa Google Apps Script para guardar en tu hoja privada.

Los datos y las cuentas se guardan en Google Sheets. Usá Actualizar desde Sheets para ver cambios de otra sesión. Si dos sesiones editan la misma versión, se bloquea el segundo guardado para evitar sobrescribir datos. Los respaldos JSON y Excel no están cifrados: guardalos en privado.
